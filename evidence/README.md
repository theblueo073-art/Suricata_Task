# Evidence

The source task requires final verification with `tree project` and `ls -la`, and the workflow recommends capturing screenshots of important milestones.

## Screenshots

Place practical screenshots in:

```text
evidence/screenshots/
```

Suggested evidence:

1. `whoami` showing `student01`.
2. Initial project directory structure.
3. `report.txt` after the `nano` edit.
4. `.secret.txt` creation and later `classified.txt`.
5. `install.sh` content and executable permission.
6. `classified.txt` permission.
7. `admin_notes.txt` owner-only permission before deletion.
8. Final `tree project`.
9. Final `ls -la` permission/location checks.

These filenames are suggestions only; the uploaded task does not prescribe screenshot filenames.

## Terminal Output

Store useful copied terminal output in:

```text
evidence/terminal-output/
```

Do not place passwords, private keys, tokens, or unrelated sensitive information in the repository.
