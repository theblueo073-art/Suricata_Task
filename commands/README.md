# Command Reference

`commands.sh` is a commented **manual runbook**. Do not execute the whole file as a batch: some steps require you to inspect your network, edit YAML interactively, replace placeholders, or stop and investigate if a configuration test fails.

Run commands one at a time in the order shown, following [`workflow/workflow.md`](../workflow/workflow.md). Commands that change system configuration or read protected logs use `sudo`.
