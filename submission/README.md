- [ ] Complete the workflow in `../workflow/workflow.md`.
- [ ] Save real screenshots in `../evidence/screenshots/`.

- [ ] Fill `final-output.txt` with the actual results, including issues or steps that could not be completed.
- [ ] Review the main README checklist.

Use this repository as a reproducible lab record. If your tutor has requested only specific screenshots or a different report format, follow that instruction first.
